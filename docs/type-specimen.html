Same paragraphs, same navy, same display face above them — only the body typeface and its size change. The two monospaces are shown at 12.5px, which is what the site uses now; the four proportional faces at 14.5px, because a sans can carry the extra size without the line getting long. Read each block at arm's length, the way someone actually skims a page.
